What this is — and isn't

You get

  • TLS / certificate posture
  • Missing security headers (CSP, HSTS, …)
  • Cookie attribute hygiene
  • Server version disclosure
  • End-of-life dependency fingerprints
  • Mixed-content and disclosure-file checks

We never do

  • No port scanning or directory brute-force
  • No exploit attempts or payload testing
  • No login attempts or auth probing
  • No crawling beyond 5 requests
  • No vulnerability locations or PoCs in reports
  • No data retention beyond delivery
